Common Questions

Puchne Se Pehle
Jawaab Yahan

Agar pasand nahi aaya toh? +
Pehla mahina bilkul free hai — koi payment lene se pehle. Use karo, apne staff se try karwao, tab decide karo. Pasand nahi aaya toh koi sawaal nahi poochenge.
Mera data safe rahega? +
Haan — har cafe ka data completely alag aur private rakha jaata hai. Koi doosra cafe owner ya customer aapka sales data kabhi nahi dekh sakta. Aap khud bhi password se apna sensitive data protect kar sakte ho.
Purane PCs pe chalega? +
Haan, kaafi halka software hai — kisi bhi Windows PC pe chal jaata hai jo aajkal gaming ke liye use ho raha hai. Setup ke time hum check kar lete hain.
Internet band ho jaaye toh? +
Sessions chalte rehte hain local pe bhi. Internet wapas aate hi sab data automatically sync ho jaata hai — koi session ya bill loss nahi hota.
Setup ke baad support milega? +
Har plan mein WhatsApp support included hai. Koi bhi dikkat ho — naya feature chahiye ho ya bug fix — seedha message karo, usually 30 min ke andar reply milta hai.
